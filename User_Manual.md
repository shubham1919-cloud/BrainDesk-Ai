# **BrainDesk-Ai User Manual**

**Version:** 4.1.0

**Platform:** Windows

**Last Updated:** February 2026

# 1. Introduction
BrainDesk-Ai is a local AI assistant designed to help you manage tasks, access real-time data, monitor system resources, and provide contextual AI insights.
Everything runs locally on your computer, except for API calls required for specific AI functionalities.

    • WARNING: Do not modify or delete the core scripts. Tampering may break functionality and void all support.

# 2. Installation
  1. Download the latest release from the official BrainDesk-Ai website.

  2. Run the installer. You may be prompted to choose location for the installation and launch BrainDesk-Ai.

  3. Upon Launching you may be prompted to fill your details such as Name, Email and Password. You may also be prompted to choose language and region followed by choosing voice for your AI assistant.

# 3. Initial Setup
  • Grant permissions:
  
      • Microphone: For voice commands.

      • Internet: For AI processing and real-time data fetching.

      • Location (optional): Improves localized responses such as weather, tone, and accent adaptation.

      • Startup service: Required to auto start BrainDesk-Ignite

  • Configure storage location if prompted; this determines where persistent memory files are saved.

  # 4. Interface Overview
  • **Main Window:**
  
    • On the top centre you will see three buttons "Home", "Chat" and "Account". The Home is the main window of the application.
    
    • Chat Screen: Shows chat history and current chat session, a magnificient video background, A mic button and an input bar to type.
    
    • Account: Shows user details and other options such as settings.
    
    • Settings Panel: Adjust AI voice, startup behaviour, and optional permissions.
    
• **What's new Page:**

    • It shows the App version and Features shipped in the current build.
  
    • It tells users what features wil it be recieving and capabilities of the AI Application

• **BrainDesk-Ignite:**

    • It is a hands free comapnion app of BrainDesk-Ai.
  
    • It start on the startup and is triggered by hotword such as "Hey Ignite".

    • It is fast and can perform all the task which BrainDesk-Ai can do.

# 5. Troubleshooting
**• App won’t start:**  Ensure the app installed correctly, if not try reinstalling the application.

**• AI not responding:**  Check your internet connection and try restarting the application.

**• Any other issues:**  Try Restarting the application. If it dosent help try reinstalling it.
